快速上手

无需摆位位置由插件自己走（轨迹是算法生成的），没有可拖拽的点；你调的是「它怎么走」。
数值框点击进入编辑，Enter 提交、Esc 取消。双击数值框回默认值。
旋钮 / 推子旋钮上下拖；横向推子左右拖、纵向推子上下拖。按住 Shift 精调。双击回默认值。
Wet Send两个滑柄分别拖混响发送的下限 / 上限，不能交叉。
右下角三角拖动改窗口大小，双击回到 100%。
顶栏 ?打开本手册。

旋钮与推子

X / Y 轴源

X 源xsrc0 – 3 · 默认 0
0 = SIN 合成轴，1 = 输入 L，2 = 输入 R，3 = 输入 M。选输入时图形不再解析可预测，画面改用荧光点云累积。
Y 源ysrc0 – 3 · 默认 0
同上。X 与 Y 都选 SIN 时是标准李萨如图；任一侧选输入就变成「输入波形对合成轴 / 输入对输入」的示波器。
Wavewave0 – 3 · 默认 0
合成轴波形：0 sine、1 triangle、2 saw、3 square。两侧共用。

Figure

Raterate0.02 – 4 · 默认 0.40
相位推进速度（x 周期 / 秒）。越高光点跑得越快。
Ratioratio1 – 8 · 默认 2.000
y 与 x 的周期比，量化到 1/8（round(ratio×8)/8）。相位每绕回 8 个 x 周期才归零，而 8 × (n/8) 必为整数 —— 所以任意取值都严格闭合，绕回处不会出现台阶。
Phase °phase0 – 360 · 默认 90
x 轴的相位偏移（度），只加在 x 上，因此等效于 x / y 的相位差。它和 Ratio 一起决定闭合曲线的形状：某些比（如 2）改变相位只换走向不换形状，另一些比（如 3）会连续变形出不同图形。360° 与 0° 等价。
Scalescale0.05 – 1 · 默认 0.800
图形振幅。为保证不越出圆盘，振幅再乘 1/√2，1.0 时曲线正好贴到圆盘的内接正方形。

Motion

Chaoschaos0 – 0.1 · 默认 0.004
叠在坐标上的随机微颤幅度，让声音不至于机械。
Glideglide0.001 – 0.4 · 默认 0.020
Rate / Phase / Scale 的一阶平滑时间常数（秒）。越大参数变化越柔。
In GaininGain0.1 – 16 · 默认 2.00
输入轴模式下的输入增益。

Space

RoomroomSize10 – 100 · 默认 50
空间尺寸。延迟基准 = 0.1 ms + 距离 × Room，混响反馈 = 0.10 + (Room−10)/90 × 0.80（10 → 0.10，100 → 0.90）。越大越空旷、尾巴越长。
Cutoffcutoff1000 – 16000 · 默认 16000
混响的高频吸收。越低尾巴越暗。
Master GainmasterGain0 – 8 · 默认 2.00
总输出增益。
Wet Send Min / MaxminWet / maxWet0 – 1 · 默认 0.10 / 0.35
最近处 / 最远处的混响发送量，中间按深度线性插值。发送量还会再乘一次距离衰减，所以远端混响跟着干声一起变小，不会越远越糊。
Depth 渲染：输出左右两路立体声。距离从底边中央起算：pad 底部最近、顶部最远。
音量与混响的安全余量：本插件的信号链内部留了 6 dB 余量（干声与混响发送各减半），末端还有一道软膝限幅（0.85 以下完全线性）。但把 Master Gain 推到很高、同时把 Wet Send Max 也拉满时，仍可能顶到限幅器的压缩区 —— 听感上是轻微的「滋滋」或发毛。遇到这种情况，先把 Master 退回 4–6，再用 Wet Send 补混响量，不要两边同时拉满。
